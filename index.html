Connect to GitHub

One-time setup. Paste a GitHub fine-grained personal access token. It is stored only in this browser and never leaves it except in calls to api.github.com.

Recommended scope (least privilege):

  • Resource owner: climbtopher
  • Only select repositories: maven, maven-status
  • Permissions: Pull requests Read & write, Contents Read & write, Metadata Read

Create one at github.com/settings/personal-access-tokens/new. A classic repo token also works but grants write to all your repos — avoid it.
